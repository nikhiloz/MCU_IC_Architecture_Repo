# RDA5807 — Overview

## General Description

The **RDA5807M** is an ultra-low-cost single-chip FM stereo tuner by **RDA Microelectronics**. I2C controlled, no DSP. The cheapest way to add FM reception to a project.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| Manufacturer | RDA Microelectronics |
| Type | FM Stereo Tuner |
| FM Range | 50–115 MHz |
| Supply Voltage | 2.7–3.6 V |
| Interface | I2C |
| RDS/RBDS | Yes |
| Audio Output | Analog (32Ω headphone driver) |
| Package | SOP-16 |
| Current | 15 mA (typical) |

## Key Feature

- Built-in headphone amplifier (can drive headphones directly)
- Extremely low BOM cost
- Register-mapped I2C interface (16-bit registers)
