# Tools

Recommended development tools, IDEs, simulators, and debugger configurations.

## By Chip

| Chip | IDE / Toolchain | Debugger |
|------|----------------|----------|
| SI4735 | Arduino IDE / PlatformIO | Serial monitor |
| ESP32 | ESP-IDF (VS Code) / Arduino IDE | JTAG / OpenOCD |
| ATmega328P | Arduino IDE / avr-gcc / Atmel Studio | debugWIRE / AVRISP |
| RP2040 | Pico SDK (VS Code) / Arduino IDE | SWD / OpenOCD / picoprobe |
| STM32F103 | STM32CubeIDE / PlatformIO | SWD / ST-Link |
| ESP32-C3 | ESP-IDF (VS Code) / Arduino IDE | JTAG / OpenOCD |
| CC1101 | (controlled by MCU via SPI) | Logic analyser |
| RTL2832U | GNU Radio / SDR# / GQRX | N/A (USB device) |

## Diagram Tools

- [Draw.io](https://app.diagrams.net/) — block diagrams, architecture views
- [VS Code Draw.io extension](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio)
- Mermaid — inline diagrams in Markdown
