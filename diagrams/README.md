# Diagrams

Shared architectural diagrams and visualization sources.

## Format

- `.drawio` files — edit with [Draw.io VS Code extension](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio) or [app.diagrams.net](https://app.diagrams.net/)
- `.png` exports — committed alongside source files for quick viewing
- Mermaid diagrams — inline in Markdown files
